# School Activities Site

This repository contains the website for sharing school activities, clubs, events, and announcements.

## Working with this repository

Keep changes small and easy for another teacher or club lead to review:

1. Create a branch for your change.
2. Make the change and check it locally.
3. Open a pull request with a clear description.
4. Ask a second teacher to review the change before it is merged.

The pull-request checklist in [`.github/pull_request_template.md`](.github/pull_request_template.md) helps reviewers check content, links, accessibility, and safety.

## Personal repositories and organization repositories

A **personal repository** belongs to one person's GitHub account. That person manages access, settings, and ownership, even when other people are invited to contribute.

An **organization repository** belongs to a GitHub organization, such as a school, department, or club. The organization can manage members and teams, share responsibility for the repository, and use teams such as `@teachers` and `@club-leads` to review different kinds of changes. For a school project, an organization repository is often easier to maintain when staff and students need shared access.

## Repository roles

- **Teachers** review documentation and school-facing information.
- **Club leads** review website code and technical changes.
- A second teacher should review each change before it is merged.

See [`CONTRIBUTING.md`](CONTRIBUTING.md) for the contribution process and [`.github/CODEOWNERS`](.github/CODEOWNERS) for automatic reviewer assignments.
